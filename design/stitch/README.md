# מסכי Stitch

ארבעת המסכים מהאפיון (שלב 5), נוצרו ב-Stitch MCP. לכל מסך יש קובץ HTML שיוצא מ-Stitch וצילום מסך ברוחב 1440 פיקסלים.

1. מסך כניסה: `1-login`
2. מסך ראשי: `2-home`
3. אישור והמתנה: `3-confirm-wait`
4. עמוד הסיכום: `4-summary`

מערכת העיצוב: Obsidian Terminal. סגנון כהה של מסוף מסחר, ממשק מימין לשמאל, מספרים משמאל לימין, ירוק עם חץ למעלה ואדום עם חץ למטה.

## תיקונים אחרי Stitch
Stitch הוסיף כמה דברים שסותרים את האפיון. הם הוסרו מקובצי ה-HTML:
1. דירוג אנליסטים "קנייה חזקה": המוצר לא נותן המלצות קנייה או מכירה.
2. כפתורים שלא באפיון: סנכרון Bloomberg, ייצוא לאקסל, סימולציה, מודל DCF.
3. שם המודל עודכן ל-Claude Sonnet 5.5, ושמות הדוחות (10-Q, 10-K, 8-K) מוצגים תמיד משמאל לימין.
