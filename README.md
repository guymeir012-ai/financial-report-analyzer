# מנתח דוחות כספיים

כלי לאנליסטים ישראלים: מקלידים סימול של חברה אמריקאית, ומקבלים בעברית עמוד סיכום של הדוח הרבעוני או השנתי (10-Q / 10-K) עם יחסים, מה השתנה, תמחור, חדשות ומקור לכל מספר.

פרויקט גמר, קורס מפתחי AI, האוניברסיטה העברית.

## מבנה

- האפיון המלא: `spec.md`
- שרת (Python + Flask): `backend/`
- ממשק (HTML + CSS): `frontend/`
- מסכי העיצוב מ-Stitch: `design/stitch/`
- בדיקות: `tests/`

## הפעלה

העתיקו את `.env.example` ל-`.env` ומלאו מפתחות.

הפעלת השרת המקומי:

1. התקינו תלויות: `pip install -r requirements.txt`
2. ב-`.env` הגדירו `SEC_EDGAR_USER_AGENT` עם שם וכתובת אימייל (SEC דורש זאת). לתמחור (מחיר, מכפיל רווח, מתחרות) הוסיפו `FINNHUB_API_KEY` ו-`TIINGO_API_KEY` (תוכניות חינמיות); בלעדיהם העמוד עובד וקטע התמחור מציג "לא זמין כרגע".
3. הריצו מתיקיית הפרויקט: `python -m backend.app`
4. פתחו בדפדפן את http://127.0.0.1:5000 והקלידו סימול, למשל NVDA.

תשובות SEC נשמרות מקומית ב-`.cache/sec` (אפשר לשנות עם `SEC_CACHE_DIR`) ותשובות ספקי המחירים ב-`.cache/prices` (`PRICE_CACHE_DIR`), כך שפתיחה חוזרת של אותה חברה מהירה ולא שורפת את מכסת הבקשות.

## תמחור
מכפיל הרווח של החברה מחושב בקוד: מחיר אחרון (Finnhub) חלקי רווח למניה ל-12 חודשים מנתוני EDGAR (רווח לבעלי המניות הרגילות חלקי מניות בדילול של הרבעון האחרון). ההיסטוריה: מחיר הסגירה בסוף כל תקופת דוח (Tiingo) חלקי הרווח למניה שדווח אז. המתחרות והמכפילים שלהן מגיעים מ-Finnhub ומוצגים עם מקור. ההסבר בעברית נבנה ממשפטים קבועים מתוך המספרים שחושבו. JSON: `/api/valuation/<ticker>`.

## בדיקות

1. כל הבדיקות הרגילות, בלי רשת: `python -m pytest -q`
2. בדיקות דפדפן אמיתי דורשות `pip install -r requirements-dev.txt` והתקנה של Chromium, ובלעדיהן הן מדלגות.
3. בדיקות חיות מול SEC, Finnhub ו-Tiingo, דורשות `SEC_EDGAR_USER_AGENT` ואת שני המפתחות: `python -m pytest -q -m live`
4. צילומי מסך של הדפים אל `docs/screenshots/`: `python scripts/screenshots.py`
